# COS 106 Student Portfolio Project

A fully responsive, multi-page personal portfolio website built as a term project for Computer Science at MIVA Open University.

## 🚀 Features & Pages
* **Home (`index.html`)**: Personal introduction, quick bio cards, and an embedded multimedia introduction.
* **About (`about.html`)**: Detailed background, academic journey, and skills showcase.
* **Projects (`projects.html`)**: Catalog of developed work and technical implementations.
* **Academic Planner (`planner.html`)**: Interactive task manager built with JavaScript (DOM manipulation, arrays, and progress tracking).
* **Contact (`contact.html`)**: Contact form featuring real-time client-side JavaScript validation (email format, digit checks, and empty field restrictions).

## 🛠️ Technologies Used
* **HTML5**: Semantic markup structuring.
* **CSS3**: Modern styling utilizing Flexbox and CSS Grid for a fully responsive layout.
* **JavaScript**: DOM manipulation, event handling, form validation, and interactive task management logic.
* **Hosting**: GitHub Pages.
